# Project instructions

## Browser and UI testing

- Before any browser-based test, visual inspection, screenshot, or authentication-flow test on `beginner.today`, first visit `https://beginner.today/?ph_optout=1` in the same browser profile.
- Do not continue the test until the PostHog opt-out URL has loaded successfully.
- This requirement applies on every new browser session and takes precedence over opening the target page directly.
